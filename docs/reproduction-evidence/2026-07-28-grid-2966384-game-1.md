## Defect found and fixed

The first real bundle attempt failed closed because `jsonl_to_timeline.py`
placed the human-readable match ID at the timeline root but did not carry the
numeric Riot game ID into timeline provenance.

The converter now copies game and platform identity from `rofl_coverage` and
`game_info`, rejects conflicts, and never infers identity from a filename. A
regression test covers both propagation and conflict rejection.
